# Samuduha SDA Attendance

A web-based attendance tracking system built for church/SDA members, designed to make recording and managing attendance simple and accessible.

## 🔗 Live Demo
[samuduha-sda-attendance.vercel.app](https://samuduha-sda-attendance.vercel.app)

## 🛠 Built With
- HTML

## ✨ Features
- Track member attendance digitally
- Simple, accessible interface for non-technical users
- Deployed and live for real-world use

## 🚀 About
This project was built to help churches move from paper-based attendance tracking to a simple digital system — making records easier to keep and review.
